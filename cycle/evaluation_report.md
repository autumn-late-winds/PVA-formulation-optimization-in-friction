# PVA 水凝胶配方优化项目 — 综合评价报告

> 生成日期：2026-06-05
> 评估方法：Grill-Me 深度访谈（20 轮决策树遍历）
> 评估范围：SFT 微调 + 结构化 RAG 系统，含湿实验验证方案
> 评估原则：只评价，不做任何代码或文件改动

## 一、项目概览

项目构建了一套 **SFT + 结构化 RAG 驱动的 PVA 水凝胶配方优化系统**，包含四个子系统：

| 子系统 | 状态 | 评价 |
|---|---|---|
| **结构化文献知识库** | ✅ 已完成 | 63 篇论文 → 796 条 formulation cases → 多轮审核/清洗/合并，流程严谨 |
| **SFT 模型训练 + QA 评测** | ✅ 已完成 | 多尺寸对比（0.6B/1.7B/4B/8B/14B），14B 表现最佳，有系统的 benchmark 框架 |
| **配方生成 Pipeline** | ✅ 基本完成 | Generator → Audit → Diagnosis → Tree management，架构完整 |
| **湿实验验证** | ❌ 待执行 | COF 当前为随机数，尚未有真实实验数据 |

## 二、Grill-Me 决策树汇总

以下 20 轮追问中达成的重要决策：

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 比较方案 | **2 组对比**（裸基座 vs SFT+RAG），放弃 2×2 消融 |
| 2 | 搜索结构 | **链式贪心搜索**，替代原来的树结构 |
| 3 | 实验规模 | **5 个 root × 2 组 × 10 步 = 100 次湿实验** |
| 4 | 统计方法 | **Cohen's d + 学习曲线 + 终点比较**；每组 25 个样本可检测 d≈0.82 |
| 5 | 命中率定义 | COF 改善比例（vs parent）+ 终点 COF vs root，两项同时报告 |
| 6 | 文献支持策略 | **内部可追溯，外部不展示**——每个候选在内部记录 RAG 检索来源，但不嵌入配方输出 |
| 7 | 模型选择 | **14B SFT Qwen3**，需 dry-run 验证 QA 高分 ≈ 配方生成能力强 |
| 8 | 对照组处理 | 裸基座模型使用与 SFT+RAG 组相同的 prompt 约束框架（schema + audit），保证输出格式公平 |
| 9 | 盲法 | 不需要——摩擦试验机的 CSV 原始数据是客观的，无主观评分偏差 |
| 10 | 待建设 | dry-run 模型对比、RAG 检索评估（recall@K）、链式搜索代码 |

### 2.1 实验协议

```
实验结构：
┌─────────────────────────────────────────────────────┐
│  5 个 root 配方（已定义）                             │
│                                                       │
│  裸基座组（Qwen3-14B，无SFT，无RAG）                   │
│    └── 每 root 一条 10 步贪心单链 → 50 次实验          │
│                                                       │
│  SFT+RAG 组（Qwen3-14B SFT + 结构化文献库）            │
│    └── 每 root 一条 10 步贪心单链 → 50 次实验          │
│                                                       │
│  总计：100 次湿实验                                    │
└─────────────────────────────────────────────────────┘

每步规则：
  - 从当前 best 出发，单因子扰动
  - COF 改善 → 接受，继续
  - COF 变差 → 退回上一步，重新选方向
  - 链长度硬封顶 10 步

评估指标：
  - 主要：5 对 (root, 终点COF改善率) → Mann-Whitney U test
  - 辅助：10 步学习曲线，Cohen's d 效应量
```

### 2.2 统计约束

| Cohen's d | 含义 | 每组所需样本量（80% power, α=0.05） |
|---|---|---|
| 0.2 | 小效应 | ~394 |
| 0.5 | 中等效应 | ~64 |
| 0.8 | 大效应 | ~26 |

当前设计（25/组）**只能检测 d≥0.82 的大效应**。若真实效应量为中等偏小，可能得到 null result。

## 三、项目优势

1. **架构完整性** — 从文献采集 → 结构化提取 → 多轮审核 → RAG 检索 → 配方生成 → 审计 → 诊断，形成完整的闭环 pipeline。

2. **工程纪律** — 之前的 14B 评估（D 级 36/100）→ 6 个根因分析 → 5 个文件修复，展示了严谨的迭代改进能力。具体修复包括：
   - 审计失败 ≠ 实验失败 的明确区分
   - `expected_mechanism` 自动生成
   - `if_better`/`if_worse` 强制规则
   - UTF-8 编码修复
   - baseline_reproduction 定义收严

3. **领域深度** — 796 条结构化记录覆盖 papers / formulation_cases / baseline / optimized / failure_modes / optimization_rules 六个数据表，远超简单的 PDF→embedding 方案。多轮审核 pipeline（seed → curated → reviewed → merged → cleaned）保证了数据质量。

4. **实验设计** — 经过本次 grill-me，实验协议已收敛到可执行的程度：精确的样本量、明确的统计方法、公平的对照组处理。

## 四、风险与薄弱点

| 风险 | 严重度 | 说明 |
|---|---|---|
| **SFT 和 RAG 不可分解** | 🔴 高 | 2 组对比只能回答"整体系统是否优于裸基座"，无法回答"SFT 单独有用吗？RAG 在 SFT 之上还有增量吗？"——这是论文中最可能被 reviewer 攻击的点。应在论文 limitations 中坦诚说明 |
| **代理指标有效性未验证** | 🔴 高 | QA benchmark 高分 → 配方生成能力强 的映射未经检验。Dry-run 可以部分缓解此风险 |
| **效应量可能不足** | 🟡 中 | n=25/组 只能检测 d≥0.82。如果真实效应量是 0.5，将得到 null result。建议在论文中预注册统计方法，并在讨论中区分"无差异"和"样本量不足" |
| **RAG 检索未评估** | 🟡 中 | 检索组件是核心主张的一半，但目前零评测数据。无法在湿实验失败时诊断根因 |
| **链式搜索代码改动大** | 🟡 中 | 现有 pipeline 基于树结构（root/continue/rescue_candidate），改造为贪心单链需要实质性改动。这是湿实验前的关键路径依赖 |
| **Surrogate 缺失** | 🟡 中 | 没有代理模型意味着 pipeline 在湿实验前无法自测。所有验证依赖物理实验，时间和资金风险集中 |

## 五、论文主张的修正建议

### 原始主张

> "在小样本湿实验预算下，SFT+结构化RAG 比无RAG/无SFT基线更能生成连续、可执行、文献支持且有更高实验命中率的小步优化候选"

### 建议修改为

> "在本研究中，我们构建了一个结合监督微调（SFT）与结构化检索增强生成（RAG）的系统，用于 PVA 水凝胶配方的迭代优化。我们采用链式单因子搜索协议，在 5 个初始配方上进行了总计 100 次湿实验，比较了 SFT+RAG 系统与裸基座模型的优化表现。结果表明……"

### 关键变化

| 原始 | 修改后 |
|---|---|
| "比无RAG/无SFT基线更能……"（比较性主张） | "我们构建并评估了……"（描述性主张） |
| 未指定实验协议 | 明确链式、单因子、5 root、100 次 |
| 隐含声称 SFT 和 RAG 各自有用 | 承认只比较了两组，无法分解贡献 |
| 预先声称有更高命中率 | 预留结果占位，等湿实验数据填入 |

## 六、湿实验前必须完成的 Checklist

| # | 任务 | 说明 |
|---|---|---|
| 🔲 | **Dry-run 模型对比** | 5 个尺寸（0.6B/1.7B/4B/8B/14B）的 SFT 模型，各生成 10 个链式扰动候选。你作为领域专家，按 5 维度盲评（科学合理性/可执行性/多样性/安全性/RAG耦合度），每个维度 1-5 分。确认 14B 在配方生成上确实优于其他尺寸 |
| 🔲 | **RAG 检索评估** | 80/20 split 或构造 gold-standard 查询集，测量 retrieval recall@K。确认检索组件确实在返回相关信息 |
| 🔲 | **链式搜索代码** | 将现有树结构 pipeline 改造为贪心单链搜索。关键改动：移除分支逻辑，实现"接受→继续 / 拒绝→退回重选"的状态机 |
| 🔲 | **裸基座 prompt 验证** | 确保裸基座组使用与 SFT+RAG 组完全相同的输出约束框架（schema + audit），只替换模型。验证基座模型在此约束下能否产出可执行配方 |
| 🔲 | **湿实验排程确认** | 100 次实验的时间、人力、材料预算确认。保守估计：每个样品 4-6 小时工时 → 400-600 总工时 |
| 🔲 | **统计预注册** | 在实验开始前锁定：主要指标（终点 COF 改善率）、统计方法（Mann-Whitney U）、显著性阈值（α=0.05）、效应量计算方法（Cohen's d）——避免事后 p-hacking |

| 维度 | 评分 | 说明 |

## 附录 B：关键术语表

| 术语 | 定义 |
|---|---|
| **COF** | Coefficient of Friction，摩擦系数。本项目的主要优化目标（越低越好） |
| **SFT** | Supervised Fine-Tuning，监督微调。在基座模型上用领域数据训练 |
| **RAG** | Retrieval-Augmented Generation，检索增强生成。从知识库检索相关文献事实注入生成过程 |
| **DOE** | Design of Experiments，实验设计。系统性覆盖因子空间的方法 |
| **Chain Search** | 链式搜索。从 root 出发，每次只变一个因子，接受改善/退回重选，形成单链 |
| **Root** | 初始配方。5 个预定义的 PVA 水凝胶基准配方 |
| **Audit** | 配方审计。自动检查配方完整性和合规性（材料/步骤/DOE 一致性） |
| **Surrogate** | 代理模型。在无湿实验数据时用于预测 COF 的替代模型（当前为随机数） |
| **Dry-run** | 干运行。在湿实验前用模型生成配方并由专家盲评，用于验证模型选择 |
