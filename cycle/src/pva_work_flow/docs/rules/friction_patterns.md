# 往复摩擦模式判别

## 良好的摩擦模式

良好的往复摩擦表现为**规则循环 + 上下平台**，Fx-T 曲线呈现近似梯形波（上下对称）：

```
Fx (N)
  ^
  |     ┌──────────┐ 正向平台         ┌──────────┐ 
  |    /|          |\                /|          |\
  |   / | 稳态滑动  | \              / | 稳态滑动  | \
  |  /  |          |  \            /  |          |  \
  |─/───|──────────|───\─────────/───|──────────|───\──────> T (s)
  |     |          |    \       /    |          |    \
  |     |          |     \     /     |          |     \
  |     |          |      \   /      |          |      \
  |     | 反向平台  |       \ /       | 反向平台  |       \ /
  |     └──────────┘        └────────└──────────┘        └──
  |   <-- 正向滑动 -->  <-- 换向 -->  <-- 反向滑动 -->
  |       (上平台)                        (下平台)
  |   特征：
  |   - 循环形态高度相似，幅值稳定
  |   - 上半周期有明显上平台段（正向稳态滑动，Fx > 0 且恒定）
  |   - 下半周期有明显下平台段（反向稳态滑动，Fx < 0 且恒定）
  |   - 正向和反向摩擦力幅值基本对称
  |   - 无突变尖峰或周期性震荡
```

## 不良的摩擦模式

### 类型1：三角往复（无平台）

摩擦没有进入稳态，Ff 达到峰值后立刻反向，呈锯齿/三角波：

```
Fx (N)
  ^
  |    /\    /\    /\    /\    /\    /\
  |   /  \  /  \  /  \  /  \  /  \  /  \    <-- 尖峰，无平台
  |  /    \/    \/    \/    \/    \/    \/
  |─/──────────────────────────────────────\──> T (s)
  |
  |   特征：
  |   - 波形呈三角/锯齿状，无稳态平台
  |   - 说明摩擦在方向换向后立即进入"爬升→反转"，未形成稳定滑动
  |   - 常见于材料过软、润滑不良、或对偶面嵌入导致的 stick-slip
```

### 类型2：混乱不规则

循环形态各异，幅值漂移或持续变化，无重复性：

```
Fx (N)
  ^
  |  ┌─┐        ┌──┐    /\      ┌──┐
  | /   \  /\  /    \  /   \   /    \    /\
  |/     \/  \/      \/     \─/      \──/  \    <-- 形态不一致
  |──────────────────────────────────────────\──> T (s)
  |     \                                  /
  |      \                                /
  |       └──────────────┘  ┌─────────────┘
  |
  |   特征：
  |   - 各循环形态不一致，幅值漂移大
  |   - 可能伴随基线漂移（材料磨损/变形）
  |   - 可能伴有较大毛刺或周期性震荡
  |   - 说明材料在摩擦过程中持续变化（磨损失效、转移膜不稳定等）
```

### 类型3：粘滑振荡 (stick-slip)

在平台段出现高频锯齿震荡：

```
Fx (N)
  ^
  |    |/\  /\  /\|          |/\  /\  /\|          |/\  /\  /\|
  |   / |/ \/ \/ \| \       / |/ \/ \/ \| \       / |/ \/ \/ \| \
  |  /  |         |  \     /  |         |  \     /  |         |  \
  |─/───|─────────|───\───/───|─────────|───\───/───|─────────|───\─> T (s)
  |     |         |         |  |         |         |  |         |
  |     └─────────┘         |  └─────────┘         |  └─────────┘
  |                         |                      |
  |   特征：                |                      |
  |   - 平台内出现高频锯齿  |
  |   - 摩擦不是平滑滑动，而是"粘→滑→粘→滑"交替
  |   - 常见于低速度、高法向力、或缺少润滑的情况
```

### 类型4：不对称往复

正反向摩擦力幅值差异极大，一侧有明显摩擦信号，另一侧信号极弱：

```
Fx (N)
  ^
  |     ┌──────────┐          ┌──────────┐
  |    /| 正向平台  |\        /|          |\
  |   / |          | \      / |          | \
  |  /  |          |  \    /  |          |  \
  |─/───|──────────|───\──/───|──────────|───\──────> T (s)
  |     |          |    \/    |          |    \
  |     |          |    /\    |          |     \
  | ... |..........|.../..\..|..........|......\...   <-- 反向信号极小
  |     |          |  /    \  |          |       \
  |     └──────────┘ /      \ └──────────┘        \

  |   特征：
  |   - 正向和反向 Fx 幅值严重不对称（>2倍差异）
  |   - 一侧可能有明显平台结构，但另一侧信号微弱
  |   - 可能原因：传感器零位偏移、样品方向性差异、摩擦副不对中
```

## 判别关键维度

| 维度 | 良好 | 不良 |
|------|------|------|
| **循环重复性** | 各循环形态一致，幅值稳定 | 形态各异，幅值漂移 |
| **平台存在性** | 半周期内有明显平台段 | 无平台（三角波）或平台有震颤 |
| **对称性** | 正反向 Ff 幅值基本对称 | 正反向幅值明显不对称 |
| **稳定性** | COF 随时间收敛或保持平稳 | COF 持续上升/下降/剧烈波动 |
